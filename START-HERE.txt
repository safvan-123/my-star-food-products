MY STAR FOOD PRODUCTS — RETAIL SHOP SUPPLY REDESIGN (12 NOV 2026)

This ZIP keeps the SAME Next.js + Sanity project. It now focuses on
spice powders, masala blends and rice flour / kitchen essentials for shops.

WINDOWS STEP BY STEP:
1. Install a recent Node.js 24 LTS.
2. Extract the ZIP and open the project folder in VS Code.
3. Open Terminal > New Terminal (PowerShell).
4. Run:

   npm ci
   Copy-Item .env.example .env.local
   npm run dev

5. Open http://localhost:3000
6. For real product admin, follow README.md and open /studio after Sanity setup.
7. Run npm run typecheck, npm test, npm run build before deployment.

IMPORTANT: All 6 example product items are DEMO DATA, not verified live stock.
Replace sample imagery, prices, weights, ingredients and products before launch.
